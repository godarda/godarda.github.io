Introduction to {{ page.title | escape }}

MySQL is a relational database management system: software that stores information in tables and helps applications find and update it. A table has rows for individual records and columns for details such as a name, date, or price. SQL, or Structured Query Language, is used to create tables and work with their data. Related tables can be connected so information is organized without repeating the same details everywhere.

MySQL is used by websites, online stores, content systems, and business applications to store information that must still be available after an application restarts. An online store might use it for products, customers, and orders, then retrieve the details needed for a checkout. Developers and database administrators use MySQL to manage these records, control access, and keep related changes consistent when several parts of an application use the same data.

Start by creating databases and tables, choosing column types, and defining keys. You will add, find, change, and remove records, then use filters, joins, and calculations to answer questions across tables. Later lessons cover indexes, transactions, users, and permissions. Examples use MySQL on Ubuntu.

For a guided path, begin with MySQL: CREATE a DATABASE and TABLE, then follow the links at the bottom of each page. Before starting, install and run MySQL with How to set up, install, and start MySQL on Ubuntu.
