--- permalink: mongodb/ title: MongoDB (NoSQL Database) description: Explore MongoDB, a leading NoSQL database designed for modern applications. Learn the essentials of document-based storage, flexible schemas, and scalability. introduction: - >- MongoDB is a database that stores information as documents grouped into collections. A document is a record made of named fields, much like a form or a structured note; fields can also contain lists or smaller documents. This lets related information, such as a product and its options, be stored together. A relational database instead organizes information into tables, so the two approaches suit different data shapes and application needs. - >- Teams use MongoDB for web services, product catalogs, content platforms, and applications that handle changing or nested records. For example, a content system may store an article with its author, tags, and sections in one document. Developers still need to plan how information will be searched and updated, because the document structure and indexes affect speed and consistency. MongoDB is used in production systems where these trade-offs match the application's access patterns. - >- You will learn how to create a database and collection, add records, find and update them, and remove records no longer needed. The lessons explain filters for selecting matching documents, sorting and indexes for finding data efficiently, and aggregation pipelines for grouping or calculating results. You will also explore how to structure related information, connect to a server, and manage access. Examples use the MongoDB shell, a command-line tool for sending database commands. ---
